# 精品大店分析规则

## 问题定义

目标不是选一批热销 SKU，也不是给商品分配“引流款/利润款”等角色。目标是：

1. 找出商家分散在不同店铺的已验证好品。
2. 按同一国家、同一消费场景和清晰主题组合。
3. 优先建议升级一个现有店铺作为承接店。
4. 用营销参谋补充当前主题下值得验证的新品，而不是用营销参谋替代客户数据或估算客户大盘。

## 固定分析链路

1. **按 ID 还原货盘。** 用 ID 表计算，用名称表理解商品。
2. **识别已验证好品。** 在本批数据内部综合 GMV、加权 ROAS、消耗和可解释性判断；不套用跨国家统一阈值。
3. **聚合同义商品原型。** 标题只是线索，以使用场景、功能、形态和类目理解商品；`product_id` 保留为证据，不把标题相似直接当成同一商品。
4. **形成候选主题。** 每个主题只组合同一运营国家内、用户需求连续且内容表达能统一的商品。不要跨国家拼成一家店。
5. **选择承接店。** 优先考虑已有相关主题、已验证 GMV/ROAS、可承接迁入货盘和运营成本较低的现有店铺。若新开店明显更合理，必须写明原因。
6. **给出 Top 3 方案。** 默认输出三个有明显差异的主题；证据不足三组时宁可少给，并解释缺口，不凑数。
7. **再查营销参谋。** 主题确定后，只查最接近的一级/二级类目和已确认周期，补结构性缺口。

## 方案强度

每个候选方案至少检查五件事，不输出伪精确总分：

- **经营强度：** 核心候选商品在本批数据中的 GMV、加权 ROAS和投放承接。
- **主题一致性：** 商品是否服务同一用户、场景或问题，而不只是处于同一宽泛类目。
- **迁移增量：** 是否能把其他店铺的已验证商品迁入承接店。计算：

  `店外候选 GMV 占比 = 候选中来自非承接店的 GMV / 候选总 GMV`

  该指标只描述候选组合，不代表客户整体占比。
- **内容一致性：** 是否能形成统一的短视频、达人或直播表达。
- **落地可行性：** 品牌授权、库存、毛利、供应链、物流/售后、合规和店铺迁移成本。

## 商品组合边界

- 输出“建议组合、重叠提示和排除方向”，不规定主推款数量、最终 SKU 数、具体尺寸、功率档位、价格档数或套装数量。
- 不写“只保留 1 个”“首屏最多 3 档”“保留 1–2 个规格”等硬性指令。
- 同质商品可以标为“重叠候选”，说明差异应从库存、毛利、规格、供应链、内容表现和履约成本评估；最终保留方案由商家决定。
- 排除建议以主题边界为依据，例如“与高效烹饪场景无关”，而不是凭主观好恶删品。
- 不强行为每件商品设店内角色；商品清单应回答“为什么适合放在一起”。

## 指标规则

- 方案核心 GMV = 所选候选商品在 ID 事实表中的 GMV 加总。
- 方案加权 ROAS = 候选 GMV 加总 / 候选消耗加总。
- 来源店铺数以唯一 `shop_id` 计，不以店名计。
- 所有金额、比率都标明客户数据周期；跨国家只做分别展示，不直接合计。
- 消耗低于 0.01 时，即使重算 ROAS 很高也标记为低消耗方向性信号，不进入强品判断的单独依据。
- 若提供的是 Top 商品而非全量数据，禁止推算商家总 GMV、市场份额或方案覆盖率。

## 内容渠道判断

- 先看商品的可演示性、决策成本和信任门槛，再参考营销参谋中的直播/短视频 GMV 区间。
- 高客单、需要讲解、强演示或强信任的商品可倾向直播；低理解成本、前后对比强、痛点可在短时间表达的商品可倾向短视频/达人。
- 渠道结论写成“优先测试/更适合”，不写成绝对唯一渠道。
- 营销参谋的区间占比只能支持方向性判断；区间中点估算必须标注“估算”。

## AI 判断的允许范围

AI 可以判断主题命名、语义归类、商品互补性、内容钩子和风险优先级，但必须引用具体商品及数据证据。所有无法由客户数据或营销参谋直接确认的因果解释标注为“判断”或“推测”。
