# 精品大店报告设计参考

> 这是审美与节奏参考，不是逐字填空模板。允许根据证据密度和宿主能力调整卡片、表格与措辞；先满足 `references/output-contract.md`。

## 首屏

### 跑品商家精品大店建议｜客户/集团名称

> **全文报告周期**：YYYY-MM-DD 至 YYYY-MM-DD
> **生成日**：YYYY-MM-DD ｜ **识别国家**：MY / VN / ID
> ID 层级数据用于经营事实；名称对照用于理解商品和店铺；营销参谋用于验证补品。

### 核心结论

先把本报告建议的现有好品集中到对应承接店，再围绕店铺主题定向寻找达人，并按后文补品建议逐步补入同主题商品，持续去杂，把杂货型店铺收敛为相对垂直的精品店。

### Top 3 精品店主题一览

| 序号 | 国家 / 主题 | 承接店 | 类型 | 关键数据 | 判断 |
|---:|---|---|---|---|---|
| 1 | 国家<br>主题名 | 店名<br>Shop ID：ID | 重组型 / 精修型 | GMV：金额<br>ROAS：可计算值<br>店外占比：比例<br>来源店：数量 | 决策理由 |

飞书 XML 写入时用 `<colgroup>` 显式分配列宽，参考比例为 `45 / 135 / 165 / 70 / 150 / 220`；“判断”列最宽。页面宽度变化时按比例缩放，不固定行高，也不要重新拆回 8 个以上窄列。

金额只覆盖候选商品，不等于客户整体大盘，也不是新店 GMV 预测。

### 营销参谋补品

本环节用于说明：该精品店完成现有好品集中后，还可以补充哪些同主题商品。以下候选来自营销参谋对应国家、类目和报告周期内的大盘表现，作为后续开品方向，不代表必须上架。

**中文短名｜原始商品标题**

![对应商品图或截图](图片URL或本地路径)

| 字段 | 内容 |
|---|---|
| 商品定位 | 原始标题｜Product ID｜营销参谋原 Shop Name｜国家｜一级/二级类目｜准确周期 |
| 大盘表现 | 总 GMV 原始区间｜涨幅｜平均客单价 |
| 投入与渠道 | 广告消耗原始区间｜TR（估）｜Live / Video / Product Card 区间 |
| 补品判断 | 结构性缺口、重叠判断与试品风险 |
| 数据来源 | [营销参谋筛选页](筛选页URL)｜含时区采集时间 |

飞书 XML 可用约 `115 / 670` 的两列宽度。也可在同一方案候选较多时改成可横向比较的表格，但必须保留上述五组信息；不要把全部字段重新拼成一条长段落。

`TR（估） = 广告消耗区间中点 ÷ 总 GMV 区间中点`。无法形成可靠中点时写“不可计算”并保留原因。

方案 2、方案 3 沿用同一信息逻辑，但不必复制完全相同的版式。商品图应靠近自己的证据，不要先堆一排图片再放一张无法对应的表。

## 视觉提醒

- 使用一种主强调色和中性色；数字、结论和风险才加粗。
- 保持 2–3 级标题，三个方案之间留白。
- Top 3 不超过 6 个信息列；指标合并到“关键数据”，把宽度优先留给“判断”。
- 补品使用结构化证据表；图片保持独立并紧邻对应表格，长解释放“补品判断”。
- 图片大小尽量一致，URL 可点击。
- 不额外堆叠方法论、数据边界、冗长落地顺序或 AI 套话。
- 根据飞书、Aime、Mira 或其他宿主的组件自由适配，不机械复刻本页。
