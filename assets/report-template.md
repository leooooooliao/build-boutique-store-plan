## 五、落地顺序

1. 确认承接店与跨店/跨品牌授权。
2. 迁入已验证好品，对同质变体做合并评估。
3. 统一店铺主题、货架表达和内容钩子。
4. 小范围验证营销参谋补品。
5. 按实际 GMV、ROAS、内容效率和履约反馈复盘。

## 六、方法、风险与口径

- ID 主数据是唯一数值事实源；名称对照只做语义和别名关联。
- Product ID/Shop ID 校准名称重复和店铺改名。
- Top 商品截面不能代表客户整体大盘。
- 营销参谋保留平台区间；区间中点或渠道占比一律标注估算。
- 跨店迁移、授权、库存、物流/售后与合规需商家人审。
- 固定流程：双源校验、ID 聚合、双时间窗口、Top 3 比较、GCRM 证据字段和 QA。
- AI 判断：主题命名、互补/重叠关系、承接店、内容钩子和风险优先级。
